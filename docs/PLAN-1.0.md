# 1.0 规划（2026-10-17 起草）

0.9.x 的功能面已经与 Claude Code 核心能力对齐并有多处反超（精确计费、API 调试透明度、办公模式、
分层记忆 + memory 工具、消息级 rewind / 会话分叉）。1.0 的主题不是继续堆功能，而是
**把"能用的开发分支"变成"敢推荐给别人用的稳定版本"**：稳定性、文档、发布质量。

## 1.0 承诺范围（做进 1.0）

1. **稳定性与验收**
   - 三平台安装包端到端真机验收：安装、首启、旧版（0.9.x）→ 最新版升级、项目/会话/设置数据保留、卸载残留
     （沿用 docs/releasing.md 的设备验收清单，逐项勾掉）
   - 长会话压力场景：50 轮工具循环、上下文触发 micro/摘要/auto-compact 三级压缩、并行子代理 ×4
   - 崩溃与错误路径：断网 / API 429 / 会话文件损坏恢复 / 更新中断
2. **文档**
   - README 面向最终用户重写（截图、 GIF、最小上手路径）
   - CHANGELOG.md 建立（从 0.9.0 补记）
   - docs/ 收敛：releasing / PLAN-1.0 / DESIGN 各司其职
3. **发布质量**
   - Windows 代码签名（需要证书；未签名则 1.0 发布说明明确披露 SmartScreen 提示）
   - macOS 决策：购买 Apple Developer 走签名+公证，或 1.0 明确"仅 Windows/Linux"
   - 自动更新端到端验证（0.9.x → 1.0 至少覆盖 Windows 真机一次）
4. **已排期的功能收尾**（0.9.5 ~ 0.9.7 内完成）
   - 设置分层：工具开关 / 批准模式 / 权限规则的项目级覆盖
   - Skills frontmatter：allowed-tools / model 声明、模板内嵌命令
   - microCompact 阈值与保留窗口的可调化（设置页暴露）

## 1.0 验收标准（全部满足才打 1.0 标签）

- [ ] 全量测试三平台 CI 绿（当前 Windows 本机 276 通过 / 4 跳过 / 0 失败）
- [ ] 设备验收清单（releasing.md）三平台全部勾完，证据（截图/日志）归档
- [ ] 0.9.x → 1.0 升级在 Windows 真机走通：检查更新 → 下载 → 安装 → 数据保留
- [ ] 用户文档：README 上手路径 ≤ 10 分钟可独立完成；CHANGELOG 完整
- [ ] 已知局限清单发布（Windows 孤儿进程、未签名提示、macOS 平台策略），无未披露缺陷

## 1.0 非目标

- WebSearch / 图片输入（等搜索 API key 与多模态模型配置，资源到位随时插）
- 协作、云同步、移动端
- MCP OAuth / prompts / sampling（0.10 备选）
